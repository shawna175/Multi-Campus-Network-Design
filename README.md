# Multi-Campus Network Design

A five-campus university network designed and simulated using **Cisco Packet Tracer**. The project demonstrates subnetting, inter-campus routing, centralized network services, and wired and wireless connectivity.

## Project Overview

This project models the network infrastructure of a fictional university, **University of Apex**, with five campuses. Each campus has its own local network, and the campuses are interconnected through routers to support communication across the institution.

A centralized server provides DHCP, DNS, and web services. The design aims to represent a practical institutional network using concepts covered in the Computer Networks course.

## Key Features

- Five-campus network connected through five routers.
- Subnetted campus networks with wired and wireless end devices.
- OSPF routing configured for communication between campus networks.
- Centralized DHCP service with separate address pools for the campus networks.
- DNS service configured to resolve the university website.
- Web server configured to host the University of Apex webpage.
- Connectivity testing between hosts across the network.

## Network Topology

The Packet Tracer topology includes:
- Five campus routers.
- 2960-24TT switches and end devices.
- Wireless networking devices.
- A server providing DHCP, DNS, and web services.
- Serial links connecting the campus routers.

See the project report for the physical topology diagram and configuration screenshots.

## How to Open the Project

1. Install and launch **Cisco Packet Tracer**.
2. Download or clone this repository.
3. Open `CSE405_PROJECT.pkt` in Cisco Packet Tracer.
4. Explore the topology and inspect device configurations.
5. Use Packet Tracer simulation tools to test connectivity and observe network traffic.
