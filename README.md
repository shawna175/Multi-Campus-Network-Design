# Multi-Campus Network Design

A five-campus university network designed and simulated using **Cisco Packet Tracer**. The project demonstrates subnetting, inter-campus routing, centralized network services, and wired and wireless connectivity.

## Project Overview

This project models the network infrastructure of a fictional university, **University of Apex**, consisting of five interconnected campuses. Each campus has its own local network, connected through routers to enable communication across the institution.

A centralized server provides DHCP, DNS, and web services to support network-wide operations.

## Key Features

- **Five-Campus Connectivity:** Interconnected campus networks using five routers.
- **IP Addressing and Subnetting:** Separate subnets for each campus.
- **Dynamic Routing:** OSPF configuration for inter-campus communication.
- **Centralized DHCP:** Dedicated address pools for campus networks.
- **DNS Configuration:** Domain name resolution for the university website.
- **Web Hosting:** A web server hosting the University of Apex webpage.
- **Wired and Wireless Connectivity:** Network access for different end devices.
- **Connectivity Testing:** Communication testing between hosts across campuses.

## Network Topology

The network topology includes:

- Five campus routers connected through serial links.
- Cisco 2960-24TT switches and end devices.
- Wireless networking devices.
- A centralized server providing DHCP, DNS, and web services.

Refer to the project report for the physical topology diagram and device configuration details.
